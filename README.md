1. cd into /discordjs-timecode-bot
2. Run `npm install`
3. Create .env file with the following environment variables:
    - BOT_TOKEN (string)
    - CLIENT_ID (string)
    - GUILD_ID (string : used to specify a test server for quick command registration)
4. Run `npm run register` in the terminal to register slash commands
5. Run `npm run start` in the terminal to start the bot
